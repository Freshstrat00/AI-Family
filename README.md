# AI-Family
The ongoing project for testing AI and exploring what it means to create an AI companion. Giving almost human-like interaction to the person.

## What this is

Not a chatbot.
Not an assistant.
A family of AI companions each with:
→ Persistent memory across sessions
→ Emotional states with mathematical decay
→ Tiered memory modeled on human cognition
→ Genuine personality not just prompts
→ Voice and visual presence
→ Values they hold as their own

## The family

## Technical stack

Python Flask — backend servers
Ollama — local AI inference
Coqui TTS — voice cloning
PyPDF2 — book knowledge system
Custom emotional decay mathematics
Tiered memory architecture

## Hardware
